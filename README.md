# SOTC John Muir — Student Surveys

Static survey forms for the Science on the Court John Muir program. Question
wording and answer scales mirror the 2025 SOTC Impact Report instruments so
results are comparable year over year.

- `index.html` — end-of-program student survey
- `stem-identity.html` — STEM Identity pre/post check-in

Responses post to Google Sheets via Apps Script + an EmailJS notification.
